# CopyMonster

> **The Brand DNA Operating System**  
> *Your Brand Has a DNA. CopyMonster Is the System That Keeps It Alive.*

Define your brand once. Then launch funnels, pages, automations, ads, emails, and entire campaigns — all powered by the same versioned strategic memory. No prompt drift. No generic AI. No rebuilding your voice from scratch every time you open a chat.

---

### The Rule: No DNA. No Copy.

#### The Problem: Generic AI Is Killing Your Brand Essence
AI democratized content creation. It also democratized generic output. Every expert, infoproductor, and mentor now has access to the same models, the same prompts, and the same vocabulary — which means every brand sounds identical to the next.

The result is a paradox: the more you produce, the less you sound like yourself.

CopyMonster was built to close that gap. Not with better prompts. With structural memory.

- **Strategy First, Copy Later**: Intelligence without identity is just noise. Gain a structural competitive advantage by defining your DNA before you write a single line.
- **Prompt vs. Memory**: Stop relying on temporary prompts and fragile chat sessions. Build a permanent strategic memory that grows with your business.
- **Unified Identity**: Ensure every agent — from copywriting to sales sequences — communicates with the exact same voice, authority, and values.

---

## Core Infrastructure

### One DNA. Every Agent. Zero Drift.
The **Brand DNA Engine** is the foundation of everything CopyMonster does. Through a guided 12-block strategic interview, the system maps your promise, persona, pain points, unique mechanisms, tone of voice, objections, and offer architecture into a structured, versioned document. That document becomes permanent memory. Every agent you deploy — copy, funnel, email, ads, automation — reads from the same source. You never rewrite your brand context again.

- **12-Block Strategic Map**: Map your history, values, positioning, ICP pain points, and offer architecture through an oriented 12-block framework.
- **Immutable Versioning**: Track DNA evolution across v1, v2, and v3 releases. Never worry about accidental prompt drift or overwritten intelligence.
- **Opt-In Injection**: Choose which DNA powers each session. The structured `POSITIONING CONTEXT` block is injected into the runtime automatically — or choose "No DNA" when you want a clean slate.
- **Multi-DNA Management**: Manage multiple brand profiles in *Settings → My DNA*. Create, resume, duplicate, set as default, archive, and refine — ideal for agencies and multi-product creators.

## Multi-Agent Architecture

### Deploy Specialized Agents That Share the Same Brain
CopyMonster is not a single chatbot. It is an orchestration layer where every capability is an agent — and every agent reads from the same Brand DNA. The agent that writes your VSL, the agent that builds your funnel, the agent that sequences your emails, the agent that analyzes your market — they all operate from one strategic memory. Consistency is structural, not manual.

- **Copywriting Agents**: Presets for VSL scripts, paid ads, email sequences, landing pages, and sales copy — each calibrated to your DNA and to proven direct-response frameworks.
- **Funnel & Launch Agents**: Build the entire funnel from a single brief: opt-in, sales page, order bump, upsell, thank-you. Every page ships with the same voice.
- **Research & Market Agents**: Web search, page scraping, and competitive analysis — feeding insights back into your versioned DNA.
- **Planning & Delegation**: Planning mode, goal management, task lists, subagent delegation, and background execution. The system structures complex work before it runs.

## Connected Workflows (MCP)

### Your Brand DNA, Inside the Tools You Already Use
CopyMonster speaks MCP (Model Context Protocol) — the open standard for connecting AI agents to external tools. That means your DNA can travel with you: into your CRM, your payment stack, your messaging, your analytics, your file system, your repositories. No vendor lock-in. No manual copy-paste between systems. Your strategic memory is portable, versioned, and sovereign.

- **MCP Connectors**: Connect Supabase, WhatsApp, Stripe, Notion, GitHub, Google Drive, and any service with an MCP server.
- **Workspace Context**: The agent works inside a selected workspace — files, tasks, and context tied to that area.
- **File & Shell Tools**: Read, create, edit, and search files. Execute shell commands in a sandbox. Combine file changes with operational tasks.
- **Approval & Permissions**: Every sensitive operation follows the active permission policy. The interface requests approval when the policy requires it — never unrestricted by default.

## Getting Started

Transform your brand in three steps:

1. **Step 1: Define Your DNA** — Answer 12 strategic blocks to build your Brand DNA map. This establishes the permanent memory layer for all agents.
2. **Step 2: Apply Your Brand DNA** — Use your Brand DNA as a shared reference when creating and refining marketing assets.
3. **Step 3: Scale & Evolve** — Run campaigns across ads, email, and organic channels. Feed real-world conversion metrics back into your versioned DNA.

### Quickstart (Local Development)

```sh
# Clone your fork
git clone https://github.com/Integridade-Digital/copymonster-launch.git
cd copymonster-launch

# Install dependencies and build
pnpm install
pnpm run build

# Start the web UI (default: http://127.0.0.1:3080)
pnpm dsh web
```
